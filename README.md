# 🌌 Nova Command Center

A customizable, productivity-focused **New Tab Dashboard** built for the **Hack Club Stardance** challenge.

Nova Command Center replaces the default browser new-tab page with a clean glassmorphism dashboard containing useful information, productivity tools, and customizable shortcuts.

## ✨ Features

### 🕐 Clock & Greeting
- Live digital clock
- Current date
- Dynamic greeting based on the time of day

### 🔎 Search
- Search directly from the new-tab page
- Simple, fast search interface

### 🌦️ Weather
- Live weather information
- Temperature and weather details
- Uses a weather API

### 🚀 NASA Astronomy Picture of the Day
- Displays NASA's Astronomy Picture of the Day
- Shows the title and date
- Supports NASA image/video responses
- Handles unavailable API responses

### 📝 Todo List
- Add tasks
- Remove tasks
- Simple productivity-focused interface

### 🌙 Dark / Light Theme
- Switch between dark and light themes
- Theme preference is stored locally
- Theme remains selected after refreshing

### 🔗 Custom Quick Links
- Add your own websites
- Edit existing links
- Delete links
- Save links using Local Storage
- Open saved websites directly

### 🍅 Pomodoro Focus Timer
- 25-minute focus session
- 5-minute break session
- Start, pause, and reset controls
- Automatic focus/break switching
- Completed session counter
- Session count persists using Local Storage
- Browser notifications when a session changes
## 🎨 Design

Nova Command Center uses a modern **glassmorphism + futuristic dashboard** design.

- Dark futuristic interface
- Glass-style cards
- Responsive layout
- Hover animations
- Smooth transitions
- CSS variables for theme management
- Mobile-friendly layout

## 🛠️ Technologies Used

- **HTML5** — page structure
- **CSS3** — layout, styling, animations and themes
- **JavaScript** — interactivity and application logic
- **Local Storage API** — persistent user data
- **Weather API** — weather information
- **NASA APOD API** — astronomy picture data
- **Font Awesome** — icons
- **Google Fonts** — typography

## 🔐 API Keys

Do not commit private API keys to a public GitHub repository.

For a public deployment, use a secure approach for API credentials rather than placing private keys directly in client-side JavaScript.

## 💾 Local Storage

The project uses browser Local Storage for:

- Theme preference
- Custom quick links
- Pomodoro session count

This lets the dashboard remember user preferences without a backend.

The goal of Nova Command Center is to create a **useful, attractive, and genuinely customizable new-tab experience** rather than just another static landing page.

The project focuses on:

**Layout** → flexible dashboard structure

**Styling** → futuristic glassmorphism interface

**Interaction** → search, APIs, todos, themes, quick links, timer and personalization

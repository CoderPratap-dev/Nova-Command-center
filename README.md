# Nova Command Center

A simple custom new tab page I made for the Stardance mission.

It replaces the default new tab with a clean space-themed page using NASA's Astronomy Picture of the Day as the background.

<img width="1877" height="908" alt="Screenshot 2026-08-02 161940" src="https://github.com/user-attachments/assets/d6a46b38-1326-4fab-953e-8d243bab8c9a" />


## Features

- Live clock
- Current date
- Time-based greeting
- Google search
- Quick links
- Simple todo list
- Tasks are saved using localStorage
- NASA APOD background
- Responsive design

## Built With

- HTML
- CSS
- JavaScript

## API

NASA Astronomy Picture of the Day (APOD)

## How to use

Open `index.html` in a browser.

Or use the deployed version:

**Live Demo:** https://coderpratap-dev.github.io/Nova-Command-center/

## Project

Made as part of the Stardance Build Your Own Custom New Tab Page mission.
